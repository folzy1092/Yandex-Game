PT Sans
--------
Source:  https://fonts.google.com/specimen/PT+Sans
Author:  ParaType (Alexandra Korolkova, Olga Umpeleva, Vladimir Yefimov)
License: SIL Open Font License 1.1
         https://openfontlicense.org/

File used (Assets/Resources/Fonts/):
  PTSans.ttf  — the font every label in the game is drawn with

Unity's built-in font ships without Cyrillic glyphs in a WebGL build, so the
entire Russian interface rendered as blank space on the first Yandex draft
upload. PT Sans was designed for Cyrillic and covers every character this
UI uses; the coverage was verified by parsing the file's own cmap table.


Downloaded models
------------------
Assets/Resources/Models/Tank.glb, SupplyTent.glb, Drone.glb — sourced from
Kenney.nl / public CC0 model sites, per the setup steps in
DroneStrike/README.md. Scale is unverified per-model and corrected at build
time by TargetProps.NormalizeModelSize.

Assets/Resources/Models/Trench.glb — "Sack Trench" by Quaternius
Source:  https://poly.pizza/m/LW3jwpPfiN
License: Creative Commons CC0 1.0 Universal (public domain)
         https://creativecommons.org/publicdomain/zero/1.0/
Scale and segment length are unverified — see TrenchSegmentSpan and
TrenchModelYawOffset at the top of MissionBuilder's Berm() method.


Everything else — every other texture, material, sound and 3D shape in the
game — is generated procedurally at build or run time from code, and carries
no external licence.
