# Drone Strike

Симулятор ударного FPV-дрона для Яндекс Игр. Игрок пилотирует дрон-камикадзе и
уничтожает наземные цели: технику, склады, антенны.

Сеттинг абстрактный, целей-людей нет — только техника и объекты. Это
осознанное решение: привязка к реальному конфликту поднимает возрастной
рейтинг и риск отказа на модерации, что режет охват и рекламный доход.

## Текущее состояние

Готово к отправке на модерацию: главное меню с выбором борта, боеприпаса и
карты, три карты, полёт, цели, подрыв, огонь на обломках, батарея, связь, HUD,
экран результата, четыре рекламные площадки.

Спеки: `docs/superpowers/specs/2026-08-23-drone-strike-core-design.md` (ядро),
`docs/superpowers/specs/2026-08-24-drone-strike-release-pass-design.md`
(карта, баги, меню, монетизация).

## Карты

Три карты строит один `MissionBuilder` по профилю — размер, рельеф, число целей
каждого типа, густота леса, освещение. Три копии билдера — это три места, куда
может уехать одна правка, поэтому копий нет.

| Карта | Дорога | Целей | Особенность |
|---|---|---|---|
| Опорный пункт | кольцо 190×150 | 13 | ровное поле, дневной свет |
| Лесная дорога | кольцо 144×200 | 14 | холмы, вдвое гуще лес, низкий подлёт |
| Перекрёсток | кольцо 230×170 + крест | 19 | сумерки, длинные тени, самая насыщенная |

Вторая и третья открываются прохождением предыдущей **или** рекламой.

Ничего не расставлено руками. Каждая позиция — это отбраковка по списку занятой
земли: цель не может встать внутрь другой, на дорогу или под дерево при любом
сиде. Длинные объекты (брустверы, стенки из мешков) занимают цепочку кругов
вдоль своей длины. Дорога проверяется отдельно: ничто не встаёт ближе 10 м к
осевой, поэтому патруль физически не может проехать сквозь что-то.

Пусковых площадок шесть, кольцом вокруг позиции. Каждая смерть дрона —
запуск с другой площадки: одна фиксированная точка означает, что к четвёртому
дрону игрок повторяет заученную линию, а не летает.

## Потолка нет

Высота ограничена тем же, чем и дальность: `SignalLink` меряет полную 3D-дистанцию
до площадки, поэтому набор высоты глушит связь ровно так же, как уход за карту.
Раньше дрон упирался в невидимый потолок — худший вид границы, останавливает и
ничего не объясняет.

## Управление

| Клавиша | Действие |
|---|---|
| W / S | наклон вперёд / назад — полёт в ту же сторону |
| A / D | крен влево / вправо — снос вбок |
| Space / Ctrl | газ вверх / вниз |
| Мышь влево-вправо | разворот дрона |
| Мышь вверх-вниз | наклон камеры |
| Esc | освободить курсор |

Камера на стабилизированном подвесе: она держит позицию и курс дрона, но
игнорирует его крен и тангаж. Летит дрон **по линии взгляда камеры** — смотришь
вниз и жмёшь W, дрон пикирует и разгоняется; выровнял камеру — летит
горизонтально. Прицеливание и пилотирование — одно действие. Боковой снос
(A/D) всегда горизонтальный, даже если камера смотрит вниз. Боевая часть
срабатывает только от удара, вручную не подрывается.

Если связь потеряна (улетел за пределы дальности) — картинка рябит сильнее,
мотор глохнет, дрон падает, и через 2 секунды боевая часть самоликвидируется.

## Как запустить

Unity **2022 LTS или новее** с модулем **WebGL Build Support**.

1. Unity Hub → New Project → шаблон **3D (Built-in Render Pipeline)** → имя
   `DroneStrike`, расположение — вне этой репы (например рабочий стол).
   Дождаться открытия, закрыть Unity.

2. Добавить пакет **glTFast** (`com.unity.cloud.gltfast`, версия `6.2.0`) в
   `Packages/manifest.json` проекта — без него загруженные модели (`.glb`)
   не импортируются. Строка уже добавлена в этот файл для существующего
   проекта; для нового — впиши руками или через Package Manager (Add package
   by name).

3. Скопировать код и модели в проект:

```bash
powershell -ExecutionPolicy Bypass -File setup.ps1 -Game DroneStrike -UnityProject "$env:USERPROFILE\Desktop\DroneStrike"
```

4. Открыть проект в Unity Hub → меню **Tools → Drone Strike → BUILD EVERYTHING**.

5. Открыть `Assets/Scenes/MainMenu.unity` → Play. Карты —
   `Assets/Scenes/Mission1..3.unity`, запускаются кнопкой «В БОЙ».

## Что проверить после сборки

- Удар в корму и в борт танка подрывает боевую часть (раньше не срабатывало).
- Палатка ловит удар и разрушается.
- Обломки горят: пламя, дым, мерцающий свет — видно с высоты.
- Патрульные грузовики едут по дороге и ни во что не въезжают.
- Улетел за ~330 м от точки пуска — «СИГНАЛ ПОТЕРЯН», мотор глохнет,
  через 2 с самоликвидация.
- Заряд от РПГ виден в нижней части кадра, у «малого» он мельче.
- «Стандарт» реально бьёт сильнее «малого» (раньше `Warhead.Awake` считал
  профиль до присвоения типа, и заряд всегда был малым).
- Танк после первого попадания темнеет и дымит.
- Компас крутится без разрывов через 0° и 180°, метки идут против
  жёлтой риски по центру.
- «Молот» в меню недоступен, пока не открыт «Шершень».
- Заряд под камерой — с острым конусом, а не капсулой, и разный у трёх бортов.
- У винтов лопасти, а не диски.
- Дрон не упирается в потолок: набирай высоту, пока не пропадёт сигнал.
- Каждый новый дрон стартует с другой площадки.
- Дороги: разметка не наезжает на перекрёстки, обочины не мерцают.
- В меню три экрана (главный, борт, боеприпас) и ничто не липнет друг к другу.
- В консоли при сборке сцены нет предупреждений `overlaps something already
  placed` и `sits on the patrol road`.

## Модели

`Assets/Resources/Models/` — загруженные с публичных площадок (Poly Pizza и
похожие, лицензия CC0) модели `Tank.glb` и `SupplyTent.glb`. `TargetProps`
использует их, если они есть, и откатывается на примитивы, если нет —
пересобирать сцену без моделей тоже можно.

Масштаб и разворот модели никто не проверял вживую (Unity на этой машине нет,
модели скачаны и подключены вслепую) — если танк или склад выйдут не того
размера или боком, крутить `ModelScale`/`ModelYawOffset` в начале
соответствующей функции в `TargetProps.cs`.

Грузовика и антенны в виде модели пока нет, обе остаются примитивами.
`Drone.glb` скачан, но не подключён — сначала нужно открыть его в Unity и
свериться с масштабом/разворотом относительно уже откалиброванного
процедурного корпуса дрона (камера, физика), прежде чем менять сам полётный
риг.

## Проверка

- [ ] Дрон взлетает по Space, летит по WASD, разворачивается мышью
- [ ] Казуальный режим сам выравнивает дрон; в спортивном угол остаётся
- [ ] Таран цели на скорости подрывает дрон, цель получает урон
- [ ] Бронетехника переживает касание по краю, прямое попадание — нет
- [ ] Уничтоженная цель чернеет и оседает, счётчик растёт
- [ ] Батарея убывает быстрее под газом, на нуле дрон падает
- [ ] При удалении картинка рябит, за пределом дальности дрон теряется
- [ ] После потери дрона через пару секунд запускается следующий
- [ ] Дроны кончились — экран поражения; все цели уничтожены — победа
- [ ] Телеметрия (скорость, высота, заряд, компас) соответствует реальности
- [ ] FPS: 60 на нормальном ПК, не ниже 30 на слабом

## Настройка баланса

| Что | Где |
|-----|-----|
| Скорость, наклон, тяга | `DroneController` |
| Чувствительность и пределы камеры | `DroneCameraGimbal` |
| Урон и радиус взрыва | `Warhead` |
| Прочность и очки целей | `Target.MaxHealth`, `Target.Points` |
| Время полёта | `DroneBattery.hoverEndurance` |
| Дальность связи | `SignalLink.cleanRange`, `maximumRange` |
| Число дронов на миссию | `MissionManager.droneCount` |
| Расположение целей | `IndustrialZoneBuilder.BuildTargets` |
