# Pool Shooter

Браузерный 3D-шутер от первого лица для Яндекс Игр. Бой всех против всех с
ботами на одной карте — бассейн, окружённый площадкой с укрытиями.

Игра полностью offline: никакого сервера, никакого бэкенда, никаких затрат на
хостинг. Противники — боты с простым AI.

## Что уже есть

- Движение: WASD, Shift — бег, Space — прыжок, Ctrl — присесть, мышь — обзор
- Пистолет: ЛКМ — огонь, R — перезарядка, магазин на 12 патронов
- Здоровье, смерть, респавн на точке подальше от живых противников
- Боты: бродят по карте случайными маршрутами, замечают цель в поле зрения,
  стреляют в игрока и друг в друга, умирают и респавнятся
- Счёт фрагов, лимит победы, экран результата с кнопками «Играть снова» и «В меню»
- Главное меню: слайдеры количества ботов (1–10) и лимита фрагов (10–100)
- Карта и все текстуры генерируются кодом — никаких покупных ассетов

## Как открыть проект

Unity создаёт свои служебные папки (`ProjectSettings`, `Packages`, `Library`),
которых нет в репозитории. Поэтому проект собирается в два шага.

**Шаг 1. Создать пустой проект Unity**

Unity Hub → New Project → шаблон **3D (Built-in Render Pipeline)** → имя
`PoolFPS_temp`, расположение — рабочий стол. Дождаться открытия, закрыть Unity.

Нужна версия Unity **2022 LTS или новее**, с установленным модулем
**WebGL Build Support** (Unity Hub → Installs → шестерёнка → Add Modules).

**Шаг 2. Перенести служебные папки в репозиторий**

```bash
powershell -ExecutionPolicy Bypass -File setup.ps1 -TempProject "$env:USERPROFILE\Desktop\PoolFPS_temp"
```

Скрипт скопирует `ProjectSettings` и `Packages` из временного проекта в
`PoolFPS/`. После этого временный проект можно удалить.

**Шаг 3. Открыть и собрать**

Unity Hub → Add → выбрать папку `PoolFPS` → открыть.
Дальше в меню Unity: **Tools → Pool FPS → BUILD EVERYTHING**.

Эта команда генерирует текстуры и материалы, строит обе сцены и прописывает их
в Build Settings. После неё открыть `Assets/Scenes/MainMenu.unity` и нажать Play.

## Проверка перед публикацией

Пройти в редакторе (Play mode), затем повторить в браузере на WebGL-сборке:

- [ ] В меню двигаются оба слайдера, подписи меняются
- [ ] Кнопка «В БОЙ» грузит карту, ботов на карте столько, сколько выбрано
- [ ] WASD, бег, прыжок, присед, обзор мышью работают
- [ ] ЛКМ стреляет, счётчик патронов убывает, R перезаряжает
- [ ] Боты **расходятся по карте**, а не идут в одну точку и не стоят на месте
- [ ] Боты не застревают в стенах и выбираются из бассейна по пандусам
- [ ] Боты стреляют в игрока и друг в друга
- [ ] Попадание по боту убивает его, счёт игрока растёт
- [ ] Смерть игрока: управление отключается, через 3 секунды респавн
- [ ] При достижении лимита фрагов появляется экран результата
- [ ] «Играть снова» перезапускает матч, «В меню» возвращает в меню
- [ ] Пол, стены, плитка бассейна и вода визуально различимы
- [ ] FPS: 60 на нормальном ПК, не ниже 30 на слабом

## Сборка под Яндекс Игры

1. `File → Build Settings` → платформа **WebGL** → `Build`, папка вывода `PoolFPS/Build/WebGL`
2. Проверить локально — WebGL нельзя открыть как файл, нужен HTTP:

```bash
python -m http.server 8000
```

3. Упаковать содержимое папки сборки в zip (архив должен содержать `index.html`
   в корне, а не вложенную папку) и загрузить в поле «Архив» в консоли
   разработчика Яндекс Игр.

## Структура кода

```
PoolFPS/Assets/
  Scripts/
    Core/    Health, Hitscan, MatchManager, SpawnManager, MatchSettings
    Player/  FirstPersonController, WeaponController, CursorRelease
    Bot/     BotController, BotFactory, BotSpawner
    World/   ProceduralTextures
    UI/      UIFactory, PlayerHUD, MatchHUD, MainMenuUI
  Editor/
    GeneratedMaterials  текстуры и материалы как ассеты проекта
    PoolMapBuilder      сцена арены
    MainMenuBuilder     сцена меню
    BuildSetup          команда «собрать всё»
```

Документация проекта — в `docs/superpowers/specs/`.

## Настройка баланса

Числа, которые скорее всего захочется покрутить после первого теста, —
публичные поля в инспекторе:

| Что | Где |
|-----|-----|
| Скорость бега, высота прыжка | `FirstPersonController` на объекте «Игрок» |
| Урон и скорострельность пистолета | `WeaponController` там же |
| Меткость, обзор, темп стрельбы ботов | поля по умолчанию в `BotController.cs` |
| Задержка респавна | `Health` |

Боты создаются кодом, поэтому их параметры правятся в значениях по умолчанию в
`BotController.cs`, а не в инспекторе.
